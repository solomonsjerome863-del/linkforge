5 Activation — win the first 10 minutes

The single biggest lever in this playbook. A signup who never crawls a site is a number, not a user. Activation = first applied suggestion. This applies equally to Systeme.io buyers — they must land in the app and crawl fast (§7 confirmation page promises <5 min).

First-session checklist (in-app)

  • Add site URL (no plugin needed — crawler handles WP/Shopify/Webflow/Ghost)
  • Crawl starts immediately, progress visible
  • Top 5 suggestions pre-sorted by score, one-click preview of source → target
  • Apply first suggestion with undo available (kill fear)
  • Confetti + “X more opportunities found” → invites second session

Instrumentation

  • Events: site_added, crawl_completed, suggestion_reviewed, suggestion_applied
  • Dashboard: activation funnel drop-offs (partially visible in Admin → Signups/Active Sites)
  • Alert: any user stuck at site_added for 24h → rescue email
  • Weekly review: where do 60% of non-activated signups die?
Kill friction ruthlessly: every field removed from signup, every minute cut from crawl time, and every default (pre-selected site type, sample suggestions) is worth more than any ad spend this quarter.

⚡ Automation — how Stripe payments provision accounts

The app ships a Stripe webhook: POST /api/billing/stripe-webhook. When the setup checklist below is complete, payments through Systeme.io/Stripe provision accounts automatically:

Stripe eventWhat the app does
checkout.session.completed / customer.subscription.created|updatedMaps the price ID → plan (Pro/Business), sets plan, subscriptionStatus = active (or on_trial), subscriptionEndsAt from the period end — matched by the customer's email
customer.subscription.deletedDowngrades to Starter, clears subscription data (same semantics as an admin downgrade)
invoice.payment_failedMarks the account unpaid
invoice.paidRe-activates a previously failed account
Any event, account email not foundLogged unprocessed in the SubscriptionEvent table — weekly reconciliation picks it up
Security note: until STRIPE_WEBHOOK_SECRET is set, the webhook audit-logs events but refuses to change any account — forged “upgrade me” requests are impossible. Signature + 10-minute replay window enforced once configured.

Fulfillment SOP — manual fallback (10 seconds per customer)

Use this when the webhook can't match a customer (email mismatch) or before the checklist below is complete:

  1. Stripe payment notification email arrives (tells you which product: $49 = Pro, $149 = Business)
  2. Log in to linkforge.digital → Admin in sidebar
  3. Search the customer's email
  4. Account exists → ⋮ → Upgrade to Pro / Business. Done in ~10 seconds.
  5. Account doesn't exist yet → they'll create it on first visit; upgrade then (Confirmation page tells them to use the same email they paid with)
Edge cases — handle these or churn happens silently:
  • Email mismatch: customer pays with billing@company.com, signs up with personal@gmail.com → webhook and admin search find nothing. Fix: confirmation page + welcome email both say “sign up with the email you paid with”; support@linkforge.digital catches the rest.
  • Automation (built): once the checklist below is complete, the webhook auto-upgrades on payment and auto-downgrades on cancellation — the manual panel becomes the fallback and the weekly reconciliation tool.
  • Refunds/disputes: refund in Stripe → webhook downgrades automatically; verify in Admin same day.
  • Weekly ritual (5 min): reconcile Stripe's active subscriber list against Admin → filter Pro/Business, fix any drift.

8 Retention & expansion

Churn is silent until it isn't. Watch for no-login in 14 days and zero applies in a week — both get automated saves before any human touch.

Keep delivering between visits

  • Weekly digest: suggestions found / applied / Est. link equity gained
  • Monthly SEO report PDF (shareable — agencies forward to clients = free marketing)
  • Citation alerts: “Your brand was mentioned on site — no backlink yet”
  • Re-crawl nudge after content updates

Expansion plays

  • Pro user adding 6th site → Business pitch with price-per-site math
  • Agency digest shows client results → upgrade for white-label
  • Annual plan offer at month 3 of healthy usage
  • Referral: give 1 month, get 1 month (both sides Pro features)

11 30 / 60 / 90-day action plan

Days 0–30 Prove it

  • Instrument funnel events + weekly dashboard review (Mon)
  • Build the Systeme.io funnel: opt-in → sales → checkout → upsell → confirmation (§7)
  • Create the 15-point checklist PDF + confirmation/onboarding emails
  • Complete the Stripe webhook checklist (env vars + endpoint) so provisioning is automatic from sale #1
  • Personal close 10 seed users from own network — founder emails, not ads
  • Communities: 5 genuine answers/week · cold email: 20 agencies/week

Days 31–60 Scale what worked

  • Publish 4 SEO articles (internal linking cluster)
  • Ship the free scanner tool as lead magnet
  • Record + embed YouTube demo
  • Launch (Product Hunt / directories) once activation > 35%
  • First case study from a paying user
  • Keep the weekly Stripe↔Admin reconciliation ritual (§7)

Days 61–90 Compound

  • Sign 2 partnership deals (WP agencies / hosting)
  • Annual plans live on both rails; offer to healthy accounts
  • Double the best-CAC channel, kill the worst
  • Referral program live
  • Review pricing + real product limits against usage data (close §7 gaps)
